Поздоровте! Ви написали, скомпільвали та розібрали свій перший програмний проект на C++. Для решти цього навчального курсу я буду фокусуватися на батька всіх мов програмування від "Hello World" до веб-серверів у мові програмування, з якої всі сучасні мови походять - C.

Як різноманітність релігій є мовами програмування. Тим не менш, є основна релігія або мова, від якої всі походять, яка є C. Я навчатиму вас C та розібратиму кожен бінарний файл протягом наступних декількох місяців, щоб ви мали повну майстерність над основною мовою всіх існування.

Коли нам потрібно розробляти в агільному середовищі, ми, звичайно, використовуватимемо Java або Python або будь-яку іншу мову швидкої розробки, однак, якщо ви бажаєте стати майстром Цифрової Інженерії, ви повинні стати одним із СЛОВА, яким у цифрових та цифрових термінах є мова програмування C.

Думайте про C як про церкву, де Python або Java або C\# ви знаходитеся в світському середовищі. C дозволить повний та повний контроль над вашим програмним проектом або середовищем, тоді як Java або Python дозволять лише частковий контроль, однак вони є необхідними мовами у сучасних бізнес-логічних середовищах швидкої розробки.

У наступному урокі ми почнемо з базової програми "hello world", як ми зробили в попередньому урокі, однак тепер ми працюватимемо з C.
