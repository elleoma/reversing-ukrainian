## part 37 - x64 c &amp; генезис життя

Для повного змісту всіх уроків, будь ласка, натисніть нижче, оскільки він дасть короткий короткий урок на додаток до тем, які він висвітлює.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

Вітаємо, що ви писали, складали та зламали свою першу програму C ++. Для решти цього підручника я збираюся зосередитись на батькові всіх мов програмування від "привіт світу" до веб -серверів мовою програмування, до яких усі сучасні мови походять від C.

Як і різноманітність релігій, є мови програмування. Тим не менш, є коренева релігія або мова, на яку весь нерест, який є C. Я збираюся протягом наступних кількох місяців навчати вас C та реверс -інженеру кожного двійкового, щоб у вас було майстерність над головною мовою будь -якого існування.

Коли нам потрібно розвиватися в гнучому середовищі, ми, звичайно, використовуватимемо Java або Python або будь -яку з інших мов швидкого розвитку, однак, якщо ви хочете освоїти кіберінженерію, ви повинні стати таким із словом, до якого в цифрових та кібер -словах є мовою програмування C.

Подумайте про C так, ніби ви перебуваєте в церкві, де Python або java або c \# ви перебуваєте у світському середовищі. C дозволить загальний та повний контроль над вашою програмою або середовищем, де Java або Python дозволить лише частково контролювати, однак вони є необхідними мовами в сучасних середовищах швидкого розвитку бізнесу.
