## part 3 - "Привіт світ"

Для повного змісту всіх уроків, натисніть нижче, оскільки він дасть короткий короткий урок на додаток до тем, які він висвітлює. https://github.com/mytechnotalent/hacking\_c-\_arm64

Сьогодні ми будемо починати на початку і взяти дуже просту програму C ++, яка не робить нічого іншого, як використовувати оператора вставки потоку, щоб надіслати рядок буквально в stdout, а потім використовувати маніпулятор кінцевої лінії для промивання вихідного буфера.

Почнемо зі створення file 0x01 \ _asm64 \ _helloworld.cpp і введемо в нього наступне.

<pre spellcheck="false">#include &lt;iostream&gt;

int main()
{
&nbsp; &nbsp; std::cout &lt;&lt; "Hello World!" &lt;&lt; std::endl;
&nbsp; &nbsp; return 0;
}
</pre>

Давайте складемо і посилаємося.

<pre spellcheck="false">g++ -o 0x01_asm64_helloworld 0x01_asm64_helloworld.cpp
</pre>

Давайте біжимо.

<pre spellcheck="false">./0x01_asm64_helloworld
</pre>

Ми бачимо простий результат.

<pre spellcheck="false">Hello World!
</pre>
