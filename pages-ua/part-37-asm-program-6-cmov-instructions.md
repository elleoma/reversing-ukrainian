## PART 37 - Програма ASM 6 \ [CMOV Інструкції \]

Для повного змісту всіх уроків, будь ласка, натисніть нижче, оскільки він дасть короткий короткий урок на додаток до тем, які він висвітлює.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

У нашій шостій програмі ми продемонструємо, як ми можемо працювати з інструкціями CMOV. Перш ніж зануритися в якийсь код, давайте поговоримо про CMOV. CMOV може запобігти процесору використовувати інструкції JMP і прискорює відповідний бінар. Існують непідписані інструкції CMOV, такі як:

Cmova або cmovnbe = вище \ [переносити прапор або нульовий прапор = 0 \]

Cmovae або cmovnb = вище або рівний \ [переносити прапор = 0 \]

Cmovnc = не переносити \ [переносити прапор = 0 \]

Cmovb або cmovnae = нижче \ [переносити прапор = 1 \]

Cmovc = носити \ [переносити прапор = 1 \]

Cmovbe або cmovna = нижче або рівний \ [переносити прапор або нульовий прапор = 1 \]

Cmove або cmovz = рівний \ [нульовий прапор = 1 \]

Cmovne або cmovnz = не рівний \ [нульовий прапор = 0 \]

Cmovp або cmovpe = паритет \ [прапор паритету = 1 \]

Cmovnp або cmovpo = не парність \ [Прапор паритету = 0 \]

Також є підписані інструкції CMOV, такі як:

Cmovge або cmovnl = більший або рівний \ [Прапор знаку xor revlow flag = 0 \]

Cmovl або cmovnge = менше \ [Прапор знаку xor refflow flag = 1 \]

Cmovle або cmovng = менший або рівний \ [прапор xor vell або zf = 1 \]

Cmovo = переповнення \ [переповнення прапора = 1 \]

Cmovno = не переповнення \ [revelt flag = 0 \]

Cmovs = підписати негативний \ [Прапор знак = 1 \]

Cmovns = не підписуйте позитивний \ [прапор значок = 0 \]

Майте на увазі, щоб переглянути взаємозв'язки між непідписаними та підписаними операціями. Непідписані інструкції використовують CF, ZF та PF, щоб визначити різницю між двома операндами, де підписані інструкції використовують SF, і для вказівки умови порівняння між операндами. Якщо вам потрібна оновлення на прапорі, перегляньте частину 14 на прапорах цієї серії. Інструкції CMOV покладаються на математичну інструкцію, яка встановлює регістр EFLAGS для роботи, а отже, зберігає програміста для використання заяв JMP після заяви порівняння. Гаразд, почнемо з рядків 21 і 22. Це не нова, яку ми пережили, оскільки ми просто переміщаємо масив у ebx. У рядку 24 ми бачимо функцію Find \ _Smallest \ _ _Value, де ми проходимо велосипед через масив і використовуємо CMOVB, щоб знайти найменше значення в кінцевому рахунку. Ми бачимо __cmp %ebx, %eax__, до якого cmp віднімає перший операнд з другого і встановлює реєстр eflags належним чином. У цей момент CMOVB використовується для заміни значення в ebx зі значенням у eax, якщо значення менше, ніж те, що було спочатку в реєстрі ebx. Після виходу з циклу ми бачимо три набори SYS \ _Writes, щоб спочатку відобразити наше повідомлення, по -друге, щоб відобразити наше перетворене ціле число до значення ASCII, а потім нарешті періоду та подачі рядків. Майте на увазі, щоб зібрати ми вводимо:

__AS –32 -o cmov \ _instructions.o cmov \ _instructions.s__

Щоб зв’язати об’єкт file, ми вводимо:

__LD -M elf \ _I386 -O CMOV \ _інструкації cmov \ _instructions.o __
