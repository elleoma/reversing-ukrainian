Цей єдиний крок створить __exit.o__ який є бінарним об’єктом file і __exit__ який є бінарним виконуваним file. Якщо ми бажаємо перетворити цей джерельний код C на збірку, нам потрібно використовувати компілятор GNU у нижченаведеному вигляді. Давайте почнемо з виконання нижченаведеної команди в терміналі:

<XyZ9PlH19ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520193559694.jpg"/></XyZ9PlH20ZuK8>

Давайте почнемо з ключа -S. Ключ -S створить порівнянну збірку AT&T Syntax джерельний код. Ключ -m32 створить виконуваний файл 32-бітовий, а ключ -O0 скаже компілятору, скільки оптимізації використовувати під час компіляції бінарного файлу. Це велика О і числовий 0. Числова 0 у цьому випадку означає відсутність оптимізації, тобто найбільш читабельний інструкційний набір. Якщо ви заміните 1, 2 або 3, кількість оптимізації зростає зі зростанням значень. <XyZ9PlH21ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520230747774.jpg"/></XyZ9PlH22ZuK8>

Цей крок вище створює exit.s який є еквівалентним джерельним кодом збірки мовою, як ми згадували раніше. Потім нам потрібно скомпільувати джерельний код збірки в бінарний об’єкт file який створить __exit.o__ file. <XyZ9PlH23ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520191376275.jpg"/></XyZ9PlH24ZuK8>

У кожному з трьох вище вказаних досліджень ви побачите майже такий самий набір інструкцій, які ми глибше вивчіть, що відбувається саме в майбутніх навчальних матеріалах. У цій серії навчальних матеріалів ми досліджували збірку мову Intel Syntax. Тепер ми змінюємо свій фокус на збірку мову AT&T Syntax, як я вже згадував раніше, оскільки ця збірка мова природно використовується в Linux з GNU Assembler і GNU налагоджувач. Найбільша різниця, яку ви побачите, полягає в тому, що в збірці мові AT&T джерельні та призначення змінені місцями. АТ&T Синтаксис: __movl %esp, %ebp__ \[This означає перемістити esp у ebp.\]

Інтел Синтаксис: __mov esp, ebp__ \[This означає перемістити ebp у esp.\]
