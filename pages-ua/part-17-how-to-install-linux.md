Частина 17 – Як встановити Linux

Для повного змісту змісту всіх уроків, будь ласка, натисніть нижче, оскільки це надасть вам короткий зміст кожного уроку, а також теми, які будуть обговорені. https://github.com/mytechnotalent/Reverse-Engineering-Tutorial

Якщо у вас немає встановленого Linux на комп'ютері в будинку, я б порадив встановити Virtual Box, який є відкритим джерелом вільної віртуальної середовища, яке ви можете встановити на своєму існуючому комп'ютері, щоб мати версію Linux, яку ви можете програмувати. <a href="https://www.virtualbox.org/wiki/Downloads " rel="nofollow noopener" target="_blank">https://www.virtualbox.org/wiki/Downloads </a>

Нижче вказані посилання на завантаження та встановлення Virtual Box, оскільки є версії для Windows та Mac. <div class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546417805.jpg"/></div>

Крім того, вам потрібно мати копію Linux, на якій я працюватиму з Ubuntu. Нижче вказані посилання на завантаження .iso file, на яку ви встановите після встановлення Virtual Box. <a href="http://www.ubuntu.com/download/desktop" rel="nofollow noopener" target="_blank">http://www.ubuntu.com/download/desktop</a>

Після завантаження вище вказаного .iso, перейдіть до свого каталогу завантажень і виконайте та запустіть __VirtualBox-5.0.24-108355-Win.exe__ або будь-яку іншу версію VirtualBox, яка зараз доступна. Якщо ви працюєте на Mac, завантажте .dmg file. Просто подвійне клікайте на file, щоб виконати та запустити його. Наступний крок – натисніть кнопку "Продовжити" та продовжуйте далі до екрану, де ви зможете вибрати свій часовий пояс, щоб вибрати кнопку "Продовжити". <XyZ9PlH39ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520096080463.jpg"/></XyZ9PlH40ZuK8>

Крім того, створіть пароль і повторіть його для перевірки та натисніть продовжити. <XyZ9PlH43ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520109220172.jpg"/></XyZ9PlH44ZuK8>

На цьому етапі встановлення операційної системи займе деякий час. Коли процес закінчиться, натисніть перезавантажити зараз. Якщо вікно замкнеться, натисніть Вимкнути машину та натисніть закрити або далі. <XyZ9PlH45ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546417404.jpg"/></XyZ9PlH46ZuK8>

На цьому етапі натисніть зелену кнопку початку. <XyZ9PlH47ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520171098505.jpg"/></XyZ9PlH48ZuK8>

Введіть свій пароль, який ви створили раніше, та натисніть Enter на своєму клавіатурі. Ви можете натиснути на сині х-шапки в правому верхньому кутку, оскільки вони лише деяка інформація, яку можна закрити. <XyZ9PlH49ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520230542621.jpg"/></XyZ9PlH50ZuK8>

Вітаємо! Ви маєте працюючу версію Linux! <XyZ9PlH51ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546418198.jpg"/></XyZ9PlH52ZuK8>

Натисніть на верхній лівий іконку та введіть terminal та подвійнокликніть на перший іконку Термінал із >\_ у вікні. <XyZ9PlH53ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546419703.jpg"/></XyZ9PlH54ZuK8>

Ви побачите іконку Термінал у нижньому лівому кутку екрана. Правокликніть на нього та виберіть Lock to Launcher, щоб він був доступний для вас після закриття вікна. <XyZ9PlH55ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520143607467.jpg"/></XyZ9PlH56ZuK8>

У вікні терміналу введіть cd Desktop та натисніть Enter. Потім введіть mkdir Code та натисніть Enter. Перший командний рух перемістить вас у каталог Desktop, а mkdir створює папку на робочому столі під назвою Code, щоб ми мали місце зберігання нашої програми, які створюємо. <XyZ9PlH57ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546424769.jpg"/></XyZ9PlH58ZuK8>

Важливо зберігати свою версію Linux на поточний момент. Кожен раз, коли ви увійдете, ви повинні вводити наступні команди. Спочатку, sudo apt-get update та натисніть Enter. <XyZ9PlH59ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520244752356.jpg"/></XyZ9PlH60ZuK8>

Далі ви повинні потім введіть sudo apt-get upgrade та натисніть Enter. <XyZ9PlH61ZuK8 class="slate-resizable-image-embed slate-image-embed__resize-full-width"><img src="/imgs/1520546418182.jpg"/></XyZ9PlH62ZuK8>

Аби працювати з 32-бітною збіркою, нам потрібно встановити пакет gcc multilib, щоб ми могли скомпільовувати 32-бітні версії мови C для дослідження. Введіть sudo apt-get install gcc-multilib та натисніть Enter. ![](/imgs/1520546711790.jpg)

Останнім кроком натисніть на __Devices__ та натисніть __Insert Guest Additions CD Image…__ для отримання краще функціональності з вашої ВМ. Цей довгий навчальний матеріал був необхідний для отримання працюючої копії Linux, щоб ми могли продовжувати наш майбутні навчальні матеріали.
