## Частина 12 - Булеве примітивне типу даних

Для повного змісту змісту всіх уроків натисніть нижче, оскільки це надасть вам короткий зміст кожного уроку, а також теми, які будуть розглянуті. https://github.com/mytechnotalent/hacking\_c-\_arm64

Сьогодні ми розмовляємо про булевий тип даних C++, який зберігає або 0 або 1 для представлення 0 для false і 1 для будь-якої речі true.

Цей вид прапора використовується широко в програмуванні загалом, і ми розглянемо ще дуже простий програму, щоб зрозуміти його просту використання.

<pre spellcheck="false">#include &lt;iostream&gt;
	
	int main()
	{
	    bool my_bool = true;

	    std::cout &lt;&lt; my_bool &lt;&lt; std::endl;

	    return 0;
	}
</pre>

Ми бачимо, що створюємо bool і присвоюємо йому true значення або 1 значення і друкуємо його.

Давайте скомпілюємо і зв'яжемо.

<pre spellcheck="false">g++ -o 0x04_asm64_boolean_primitive_datatype 0x04_asm64_boolean_primitive_datatype.cpp
</pre>

Давайте запустимо.

<pre spellcheck="false">./0x04_asm64_boolean_primitive_datatype
</pre>

Ми просто бачимо наступне.

<pre spellcheck="false">1
</pre>

Він успішно відобразив 1 в термінальному виводі stdout. Вельми просте.

Наступного тижня ми відлагодимо цю дуже просту приклад.
