## part 6 - Основна вводу/вивома

Для повного змісту всіх уроків, натисніть нижче, оскільки він дасть короткий короткий урок на додаток до тем, які він висвітлює. https://github.com/mytechnotalent/hacking\_c-\_arm64

Сьогодні ми розглянемо основну програму вводу/виводу C ++, яка має мінімальну перевірку. Перш ніж я потрапляю на коротку лекцію, коли я намагаюся тримати це коротко, я хотів пояснити, чому я not за допомогою підручника прямо _cin_ приклади, які ви бачите по всьому світу. _Cin_, стандартний вхідний потік, який бере вхід з клавіатури, називається нашим stdin. Що _cin_ - це використовувати проміжок, Tab and newline як термінатор до вхідного потоку. Наприклад, якщо ви вводите _'abc'_ and, натисніть вкладку or, покладіть нову лінію or, натиснувши повернення даних праворуч від них, буде ігноровано. Проблема полягає в тому, що якщо ви знову читаєте з _cin_, вона підбере решту даних у потоці, якщо ви зробите not, змиваючи вхідний буфер. Якби у вас був, наприклад:

<pre spellcheck="false">std::cin &gt;&gt; val1;
std::cin &gt;&gt; val2;
</pre>

Якщо користувач вводить _1_ and, то залишає простір and, то _2_ and натискає введення, у вас немає проблем. _1_ буде присвоєно _val1_ and _2_ буде присвоєно _val2_, оскільки вони прикуті. Проблема полягає в тому, що якщо ви вводите _'hey jude'_ замість цілого числа? Що відбувається, це намагається прочитати цілий and, він переходить у невдалий стан and з цього моменту, що все інше, що він витягує, є ненадійним. Я робив not, щоб бути давно звивистим, але я дуже хотів підкреслити, чому ви ніколи не використовуєте _cin_ сам по собі and, я маю на увазі ніколи! Давайте розглянемо нашу основну програму вводу/виводу, яку ми будемо налагодити на наступному уроці за допомогою дуже основної програми C ++, яка перевіряє введення. <pre spellcheck="false">#include &lt;iostream&gt;
#include &lt;sstream&gt;
#include &lt;string&gt;

int main()
{
    int age = 0;
    bool valid = false;
    char null = '\0';

    while (!valid)
    {
        std::cout &lt;&lt; "Enter Age: ";

        // Get input as string
        std::string line;
        getline(std::cin, line);

        // Init stringstream
        std::stringstream is(line);

        // Attempt to read a valid age from the stringstream and
        // if a number can't be read, or there is more than white
        // space in the string after the number, then fail the read
        // and get another string from the user and make sure the 
        // dude is at least a year old and less than or equal to
        // 100 years old
        if (!(is &gt;&gt; age) || (is &gt;&gt; std::ws &amp;&amp; is.get(null)) || age &gt;= 100 || age &lt;= 0)
            std::cout &lt;&lt; "Dude be real!" &lt;&lt; std::endl;
        else
            valid = true ;
    }

    std::cout &lt;&lt; "Your are " &lt;&lt; age &lt;&lt; " years old, seems legit!" &lt;&lt; std::endl;

    return 0;
}
</pre>

Почнемо з імпорту _IOSTREAM_, _Sstream_ and _String_. Поки що нічого хитрого. Потім ми спонукаємо користувача ввести свій вік. Потім ми створюємо рядковий об'єкт під назвою _line_ and скористатися C ++ _getline()_, що є стандартною функцією бібліотеки C ++, яка використовується для правильного читання рядка or з потоку введення. Потім ми скористаємось _stringstream_, оскільки він асоціює рядковий об’єкт із потоком, що дозволяє вам читати з рядка так, ніби це був потік, як ми зробили б із Raw _cin_. У цьому простому прикладі ми створюємо об'єкт _is_, який є коротким для введення Stringstream and, підключіть його до нашого об'єкта _line_. Потім, перш ніж ми перегукуємося з даними до STDOUT, ми робимо невелику перевірку. Спочатку ми перевіряємо, чи _age_ - це тип, який він був визначений як який є _int_ OR, чи є білий простір у потоці після даного цілого OR вік більше _100_ or менше _0_. Дуже просто це дає відповідь, якщо вхід виконує not цим критеріям. Нарешті, якщо все добре, це перегукується з простим _cout_.
