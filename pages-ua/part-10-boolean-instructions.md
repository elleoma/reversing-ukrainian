## PART 10 - Булеві інструкції

Для повного змісту всіх уроків, будь ласка, натисніть нижче, оскільки він дасть короткий короткий урок на додаток до тем, які він висвітлює.&nbsp;https://github.com/mytechnotalent/Reverse-Engineering-підручник

Існують чотири булеві інструкції, до яких існують AND, OR, XOR and NOT.&nbsp;earlier у цьому підручник. Ми побачимо цю логіку протягом усього нашого реверсування, тому важливо зрозуміти, що вона робить на індивідуальному бітному рівні.

AND = якщо перше число має 0 and, другий номер має 0, результат - 0.

AND = якщо перше число має 0 and, другий номер має 1, результат - 0.

AND = якщо перше число має 1 and, другий номер має 0, результат - 0.

AND = якщо перше число має 1 and, друге число має 1, результат - 1.

Наприклад: 0 0 1 0 0 0 1 0&nbsp;

Наприклад: 0 1 1 0 1 1 1 0

Наприклад: ———————

Наприклад: 0 0 1 0 0 0 1 0

OR = якщо перше число має 0 and, другий номер має 0, результат - 0.

OR = якщо перше число має 0 and, другий номер має 1, результат - 1.

OR = якщо перше число має 1 and, друге число має 0, результат - 1.

OR = якщо перше число має 1 and, друге число має 1, результат - 1.

Наприклад: 0 0 1 0 0 0 1 0&nbsp;

Наприклад: 0 1 1 0 1 1 1 0

Наприклад: ———————

Наприклад: 0 1 1 0 1 1 1 0

XOR = якщо перше число має 0 and, другий номер має 0, результат - 0.

XOR = якщо перше число має 0 and, другий номер має 1, результат - 1.

XOR = якщо перше число має 1 and, друге число має 0, результат - 1.

XOR = якщо перше число має 1 and, друге число має 1, результат - 0.

Наприклад: 0 0 1 0 0 0 1 0&nbsp;

Наприклад: 0 1 1 0 1 1 1 0

Наприклад: ———————

Наприклад: 0 1 0 0 1 1 0 0

NOT = якщо перше число має 0, друге число стає 1.

NOT = якщо перше число має 1, друге число стає 0.

Наприклад: 0 0 1 0 0 0 1 0&nbsp;

Наприклад: 1 1 0 1 1 1 0 1
