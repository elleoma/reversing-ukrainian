## Частина 23 – Булеві змінні

Для повного змісту змісту всіх уроків натисніть нижче, оскільки це надасть вам короткий зміст кожного уроку, а також теми, які будуть обговорені.

Наступний етап нашої подорожі – булеві змінні. Ім'я походить від великого Джорджа Буля, від якого всі сучасні комп'ютерні науки походять.

На найнижчому рівні значення може бути either 0 або 1, хибне або правдиве, + < 5 вольт або +5 вольт тощо.

Давайте вивчіть наш код.

```
int main() {
  bool isHacked = false;
  return 0;
}
```

```
int main() {
  bool isHacked = false;
  return 0;
}
```

Щоб скомпільувати цей код, ми просто набираємо:

```
gcc -o boolean boolean.c
```

```./boolean
```

УСПІШНО! Ми бачимо __0__ виведений на стандартний вивід або термінал!

Давайте розберемо це:

Ми створюємо булеву змінну під назвою __isHacked __, до якої ми присвоюємо значення __false__ або __0__. Коли ми запускаємо бінарник, ми явно бачимо значення __0__, яке успішно було виведено на стандартний вивід.

Наступного тижня ми вийдемо на глибину відлагодження булевих змінних.
